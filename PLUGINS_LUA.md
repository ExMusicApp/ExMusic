# Lua-плагины (API 2)

Плагин `.exm` состоит из **Lua-скриптов** (ZIP с `manifest.json`). Декларативных плагинов (только цвет и станции волны без кода)
больше нет — это делается скриптом. Базовое описание формата — в `PLUGINS.md`.

Скрипты работают на [LuaJ](https://github.com/luaj/luaj) (Lua 5.2) в песочнице. Пишите в подмножестве Lua 5.1/5.2:
без `goto`, без `//` и побитовых операторов (для битов есть `bit32`).

## Что нужно в манифесте

```json
{
  "id": "me.my-plugin",
  "name": "Мой плагин",
  "version": "1.0.0",
  "api": 2,
  "contributes": { "lua": { "main": "main.lua" } }
}
```

* `api` — `2` (по умолчанию).
* `contributes.lua.main` — файл скрипта внутри архива (до 512 КБ). Можно положить рядом другие `.lua` и подключать их через `require`.
* Права объявлять не нужно: любому включённому плагину доступно всё API ниже. Поле `permissions` в манифесте игнорируется.

Всегда доступны также: `plugin`, `json`, `util`, `log`/`print`, `timer`, `events`, `hooks`, `app.version`, `require`, `os.time/date/clock`,
стандартные `string`, `table`, `math`, `bit32` и базовые функции (`pairs`, `pcall`, `tostring`…).

## API

### Общее

| | |
|---|---|
| `log(...)` / `print(...)` | Пишет в журнал приложения (до 200 строк за один вызов скрипта) |
| `plugin.id`, `.name`, `.version`, `.author` | Данные из манифеста |
| `plugin.read_file(name)` | Текст файла из архива плагина (до 256 КБ) или `nil` |
| `app.version`, `app.api` | Версия приложения и API плагинов |
| `require("имя")` | Подключает `имя.lua` (или `имя/init.lua`) из архива; точка = папка: `require("lib.utils")` → `lib/utils.lua` |
| `os.time([таблица])`, `os.clock()` | Время |
| `os.date([формат [, время]])` | Дата. Поддержано: `%Y %y %m %d %H %M %S %c %x %X %%`, `"*t"` — таблица |
| `json.encode(значение)` / `json.decode(строка)` | JSON ↔ таблицы. `decode` при ошибке вернёт `nil, "текст"` |

### События — `events`

```lua
events.on("track_changed", function(track) ... end)
events.on("play_state",    function(is_playing) ... end)
events.on("ended",         function() ... end)      -- очередь закончилась
events.on("unload",        function() ... end)      -- плагин выключают или удаляют
events.on("setting_changed", function(key, value) ... end)  -- пользователь поменял настройку плагина
events.on("action",        function(key) ... end)           -- нажата кнопка из настроек плагина
```

До 16 обработчиков на событие. `events.once(имя, функция)` — сработает один раз, `events.off(имя, функция)` — снять обработчик (вернёт `true`, если он был).

### Утилиты — `util`

Чистые функции, без доступа к системе; строки до 256 КБ.
`util.url_encode(s)`, `util.url_decode(s)` (`nil` при ошибке), `util.base64_encode(s)`, `util.base64_decode(s)` (`nil` при ошибке),
`util.sha256(s)` и `util.hmac_sha256(ключ, s)` (hex), `util.uuid()`, `util.trim(s)`, `util.starts_with(s, p)`, `util.ends_with(s, p)`,
`util.split(s, разделитель [, макс_частей])` (разделитель — обычный текст, до 1000 частей), `util.clamp(x, мин, макс)`,
`util.format_duration(мс)` → `"3:07"` / `"1:02:03"`.

`track` — таблица: `id`, `title`, `artists`, `album`, `duration_ms`, `cover` (ссылка), `explicit`, `year`, `genre`, `label`,
`version`, `local` (трек с устройства).

### Настройки плагина — `settings`

Плагин описывает свои настройки в манифесте, а **рисует их приложение**: на вкладке «Плагины» у карточки плагина есть кнопка с иконкой
настроек (рядом с кнопкой удаления): она открывает **нижнюю модалку** в стиле Material 3 Expressive. Код плагина в интерфейс не попадает, поэтому испортить экран нельзя.
Значения проверяются и сохраняются приложением.

```json
"contributes": {
  "lua": { "main": "main.lua" },
  "settings": [
    { "key": "enabled_toast", "type": "switch", "title": "Уведомления", "summary": "Необязательная подпись", "default": true },
    { "key": "minutes", "type": "slider", "title": "Минут", "min": 5, "max": 180, "step": 5, "default": 30 },
    { "key": "limit",   "type": "number", "title": "Лимит", "min": 1, "max": 1000, "default": 10 },
    { "key": "nick",    "type": "text",   "title": "Имя", "max_length": 40, "default": "" },
    { "key": "mode",    "type": "choice", "title": "Режим", "default": "a",
      "options": [ { "value": "a", "title": "Вариант A" }, { "value": "b", "title": "Вариант B" } ] },
    { "key": "reset",   "type": "button", "title": "Сбросить", "summary": "Что делает кнопка" }
  ]
}
```

| Тип | Значение в Lua | Поля |
|-----|----------------|------|
| `switch` | `true`/`false` | `default` |
| `slider` | число | `min`, `max`, `step`, `default` |
| `number` | число (ввод с клавиатуры) | `min`, `max`, `step`, `default` |
| `text` | строка | `max_length` (до 500), `default` |
| `choice` | строка — `value` выбранного варианта | `options` (2–12), `default` |
| `color` | строка `"#RRGGBB"` (заглавными) | `default` (по умолчанию `#6750A4`); приложение рисует кружок-превью, поле ввода и набор готовых цветов |
| `button` | — (нет значения) | нажатие приходит событием `action` |
| `section` | — (нет значения) | заголовок группы полей: `title`, необязательный `summary` |
| `info` | — (нет значения) | поясняющий текст на цветной плашке: `title`, `summary` |

**Условный показ.** Любое поле можно показывать только при нужном значении другого поля:
`{ "key": "accent", "type": "color", "title": "Цвет", "show_if": { "key": "use_accent", "equals": true } }`.
`equals` — `true`/`false`, число или строка (для `choice` — `value` варианта). Ссылаться можно только на поле со значением
(`switch`, `slider`, `number`, `text`, `choice`, `color`). Скрытое поле не удаляется: его значение хранится и доступно через `settings.get`.

**Свой пункт в Настройках.** Если добавить в `contributes` блок `"settings_entry": { "title": "Моё", "summary": "Подпись" }`
(или просто `true`), то в главных Настройках приложения, под пунктом «Плагины», появится отдельный пункт плагина с его иконкой.
Нажатие открывает ту же нижнюю модалку настроек. Пункт виден, пока включены и плагин, и вся система плагинов; нужно хотя бы
одно поле в `settings`.

Общие поля: `key` (латиница в нижнем регистре, цифры, `_`; до 32 символов; уникальный), `type`, `title` (до 60), `summary` (до 160).
До 30 полей. 
В скрипте: `settings.get("minutes")` — текущее значение (или `default`; для несуществующего ключа, кнопки, заголовка и текста — ошибка).
`settings.all()` — таблица `{ключ = значение}` для всех полей со значением.
`settings.set(ключ, значение)` — плагин сам меняет свою настройку (значение проверяется так же, как ввод пользователя; возвращает
`true`, если принято). Новое значение сразу видно в `settings.get`, а событие `setting_changed` в этом случае **не приходит**
(чтобы скрипт не зациклился на своих же изменениях).
Об изменениях сообщает `events.on("setting_changed", function(key, value) ... end)`, о нажатии кнопки — `events.on("action", function(key) ... end)`.
Пока плагин или вся система плагинов выключены, настройки можно менять — значения сохраняются, события приходят после включения.

### Свои страницы настроек из Lua — `ui.settings_page`

Манифест описывать не нужно: плагин сам создаёт страницу настроек и пункт в Настройках прямо из скрипта. Рисует страницу приложение
(Material 3 Expressive), а значения и логику держит Lua.

```lua
local st = storage.get("state", { loud = false, volume = 50 })

ui.settings_page {
  id = "main",                 -- a-z, 0-9, _ (до 32 символов)
  title = "Мой плагин",        -- название пункта (до 60 символов)
  summary = "Подпись пункта",  -- необязательно (до 100)
  menu = true,                 -- пункт в главных Настройках (по умолчанию true); false — только в карточке плагина

  render = function()          -- вызывается при открытии страницы и после КАЖДОГО действия пользователя
    local list = {
      { type = "section", title = "Звук" },
      { type = "switch", id = "loud", title = "Громко", value = st.loud,
        on_change = function(v) st.loud = v; storage.set("state", st) end },
    }
    if st.loud then              -- условный показ — обычный Lua
      list[#list + 1] = { type = "slider", id = "volume", title = "Уровень", min = 0, max = 100, step = 5,
        value = st.volume, on_change = function(v) st.volume = v; storage.set("state", st) end }
    end
    return list
  end,
}
```

`render` возвращает список компонентов (до 80). Общие поля: `type`, `title` (до 80 символов), `summary` (или `text`, до 200),
`id` (необязательный, латиница/цифры/`_`, уникальный на странице; нужен, если порядок компонентов меняется — по нему интерфейс
помнит ввод), `on_change(значение)` / `on_click()` — колбэк.

| `type` | Поля | Значение в `on_change` |
|--------|------|------------------------|
| `section` | `title`, `summary` | — (заголовок группы) |
| `info` | `title`, `text` | — (плашка с пояснением) |
| `switch` | `value` (bool) | `true`/`false` |
| `slider`, `number` | `value`, `min`, `max`, `step` | число (уже в диапазоне и по шагу) |
| `text` | `value`, `max_length` (до 500) | строка |
| `choice` | `value`, `options` — список `{ value = "a", title = "Вариант A" }` или просто строк (2–12) | `value` варианта |
| `color` | `value` — `"#RRGGBB"` | `"#RRGGBB"` |
| `button` | `on_click` | — |

Что гарантирует приложение: типы, длины, диапазоны и значения проверяются (кривое значение заменится на безопасное, ошибка
в `render` попадёт в статус плагина, а прежняя страница останется); колбэк вызывается уже с проверенным значением; повторные
изменения сливаются в одну перерисовку. Страницы работают, пока плагин и система плагинов включены; при выключении пункты
пропадают, при выключении плагина колбэки не вызываются.

Остальное: `ui.refresh([id])` — перерисовать страницу (или все свои), если данные изменились не из интерфейса (например, пришёл
ответ по сети); `ui.remove_page(id)` — убрать страницу. Страниц не больше 8 на плагин.
Пункт можно создавать и динамически, в любой момент: например, добавить страницу, когда пользователь вошёл в аккаунт сервиса.
Кнопка-шестерёнка в карточке плагина открывает нижнюю модалку со всеми его страницами; пункт в Настройках — только одну.

Декларативные настройки из манифеста (`contributes.settings`, см. выше) остаются и работают вместе со страницами из Lua.

### Диалоги и модалки — `ui`

Всё рисует приложение; скрипт получает результат в колбэках. В каждом окне подписано имя плагина, поэтому выдать окно
за системное нельзя. Колбэки вызываются в потоке Lua, как обычные события.

| Вызов | Что делает |
|-------|-----------|
| `ui.alert(заголовок, текст [, on_close])` | Окно с кнопкой «Понятно» |
| `ui.confirm(заголовок, текст, on_yes [, on_no])` | «Отмена» / «ОК»; закрытие без выбора = «Отмена» |
| `ui.prompt(заголовок, текст, начальное, on_submit [, on_cancel])` | Окно с полем ввода; `on_submit(текст)` (до 500 символов) |
| `ui.dialog{...}` | Окно с своими кнопками, см. ниже |
| `ui.sheet{...}` | Одноразовая **нижняя модалка** с компонентами (как у страницы настроек) |
| `ui.open_page(id)` / `ui.close_page([id])` | Открыть свою страницу настроек нижней модалкой / закрыть модалку |

Окна возвращают номер окна или `nil`, если открыть нельзя: не чаще раза в 1,5 с и не больше 3 неотвеченных окон на плагин.
Заголовок до 80 символов, текст до 600.

```lua
ui.dialog {
  title = "Что делаем?",
  text = "Текст окна",
  buttons = {                                   -- до 3 кнопок; style: "default" | "primary" | "danger"
    { title = "Удалить", style = "danger", on_click = function() ... end },
    { title = "Готово",  style = "primary", on_click = function() ... end },
  },
  input = { value = "по умолчанию", hint = "Подсказка", max_length = 60 },  -- необязательно; или input = true
  cancelable = true,                            -- false: закрыть можно только кнопкой
  on_dismiss = function() ... end,              -- закрыли без выбора (назад, касание вне окна)
}
```
Если у окна есть `input`, колбэк кнопки получает введённый текст: `on_click = function(text) ... end`. Без кнопок
показывается «Понятно». Название кнопки — до 24 символов.

```lua
ui.sheet {
  id = "counter",                               -- по умолчанию "sheet"
  title = "Счётчик", summary = "Подпись",
  render = function()                           -- те же компоненты, что и в ui.settings_page
    return {
      { type = "info", title = "Значение: " .. n },
      { type = "button", title = "Прибавить", on_click = function() n = n + 1 end },
      { type = "button", title = "Закрыть", on_click = function() ui.close_page("counter") end },
    }
  end,
  on_close = function() ... end,                -- шторку закрыли (пальцем или ui.close_page)
}
```
`ui.sheet` открывается сразу и удаляется после закрытия; она не попадает ни в Настройки, ни в карточку плагина. Шторка перерисовывается
после каждого действия внутри неё; если данные поменялись извне — вызовите `ui.refresh("counter")`. Одновременно открыта одна шторка плагина.

**Изменение объектов.** Страницу можно в любой момент пересоздать с тем же `id`: `ui.settings_page{ id = "main", title = "Новое имя",
render = другая_функция }` обновит название, подпись и содержимое на лету. Содержимое компонентов меняется через `render`: достаточно
поменять данные в Lua и вызвать `ui.refresh()`. `ui.remove_page(id)` удаляет страницу вместе с пунктом в Настройках.

### Плеер — `player`

`play()`, `pause()`, `toggle()`, `next()`, `previous()`, `seek(мс)`, `position()`, `duration()`, `is_playing()`,
`volume()`, `set_volume(0..1)`, `speed()`, `set_speed(0.5..2)`, `current()` — таблица трека или `nil`.

Ещё: `seek_by(мс)` — перемотка относительно текущей позиции (в пределах трека); `queue()` — очередь только для чтения, до 100 треков
начиная с текущего: `{ index, id, title, artists }`; `queue_size()`, `queue_index()` (с 1 или `nil`); `skip_to(n)` — перейти к треку `n` очереди
(с 1; `true`, если такой есть).

### Уведомления — `ui`

`ui.toast(текст)` — всплывающее сообщение внизу экрана (не чаще раза в 1,5 с, до 200 символов).
Остальные окна и модалки — в разделе «Диалоги и модалки» ниже.

### Хранилище — `storage`

`get(ключ [, по_умолчанию])`, `set(ключ, значение)` (`nil` удаляет), `delete(ключ)`, `keys()`, `clear()`.
Значения — числа, строки, булевы, таблицы (в т. ч. вложенные; без функций и циклических ссылок). Ключ: до 48 символов
`A-Za-z0-9_.:-`, значение до 64 КБ, не больше 200 ключей. Данные личные для плагина и стираются при его удалении.

### Интернет — `http`

```lua
local r, err = http.get("https://example.com/api", { Authorization = "Bearer ..." })
if not r then log("ошибка: " .. err) return end
-- r.status, r.ok, r.body (до 1 МБ), r.headers (имена в нижнем регистре)
local r2 = http.post("https://example.com/api", { a = 1 })   -- таблица уйдёт как JSON, строка — как текст
```

Есть также `http.put(url, тело, заголовки)`, `http.patch(url, тело, заголовки)`, `http.delete(url, заголовки)` и `http.head(url, заголовки)`;
ограничения у всех методов одни и те же.

Только `https`, редиректы не выполняются (вернётся статус 3xx и заголовок `location`), на локальные адреса ходить нельзя,
до 30 запросов в минуту. Токены и данные аккаунта Яндекса плагинам **не передаются**.
Запрос блокирует только ваш скрипт, не приложение.

### Тема — `theme`

`theme.set_accent("#RRGGBB")` (`nil` — снять), `theme.set_amoled(true|false)` (`nil` — снять).
Действует, пока плагин включён; перекрывает цвет из настроек.

### Волна — `wave`

* `wave.add_station(название, станция [, подпись])` — станция в окне «Включить волну» (до 40; повтор той же станции обновляет её).
  `станция` — идентификатор вида `тип:значение`, например `genre:rock`, `mood:calm`, `activity:workout`.
* `wave.clear_stations()` — убрать свои станции.
* `wave.start(станция [, название])` — **сразу запустить** волну (заменит текущую очередь).

### Хуки — `contributes.hooks` и `hooks`

Хук — кусок кода плагина, который пользователь может включать и выключать. **Всё находится в плагине**: в приложении нет ни логики
хуков, ни готовых «точек»; приложение только рисует выключатели и вызывает ваш обработчик, когда хук включается или выключается.

**1. Объявить хуки в манифесте** (id — как ключ настройки: `a-z`, цифры, `_`, до 32 символов, «enabled» и «unsafe» заняты; до 8 хуков):

```json
"contributes": {
  "lua": { "main": "main.lua" },
  "hooks": [
    { "id": "my_hook", "title": "Название хука", "summary": "Что он делает" }
  ]
}
```

Элемент — объект `{ id, title, summary }` (title до 60 символов, summary до 160) или просто строка с id.

**2. Написать код хука в Lua:**

```lua
hooks.on("my_hook", function(active)
  if active then   -- хук включили: применить
  else             -- хук выключили (или плагин останавливают): откатить
  end
end)
```

**3. Настройки и установка.** Если хуки объявлены, в настройках плагина **всегда** есть раздел «Хуки» с главным выключателем
«Включить хуки» и по выключателю на каждый хук (видны, когда главный включён). **По умолчанию хуки выключены.** При установке плагина
с хуками в окне перечислены хуки и задан вопрос «Включить хуки?» (по умолчанию выключено; при обновлении стоит прежний выбор).
Пока хуки выключены, обработчики не вызываются вообще. Обработчик получает `true` после запуска скрипта (если хук разрешён) и при
включении хука пользователем, `false` — при выключении хука, при выключении главного выключателя и при остановке плагина.

Выключатели хранятся как поля `hook_enabled`, `hook_unsafe` и `hook_<id>`: свои поля с префиксом `hook_` объявлять нельзя, а
`settings.set` для них запрещён (решает только пользователь). Прочитать их можно через `settings.get(...)`.

**API `hooks`:**

| Вызов | Что делает |
|-------|-----------|
| `hooks.on(id, функция(active))` | Код хука. Хук должен быть объявлен в манифесте. На один хук один обработчик |
| `hooks.off(id)` | Снять обработчик (вернёт `true`, если он был) |
| `hooks.refresh([id])` | Ещё раз вызвать код включённого хука (с `true`). Выполняется отдельным вызовом |
| `hooks.enabled(id)` | `true`, если пользователь разрешил этот хук (включены главный выключатель и выключатель хука) |

#### Отключённая песочница (ОПАСНО)

Плагин, которому нужен Java-код, объявляет `"unsafe_java": true` в `contributes` (нужен хотя бы один хук). Тогда в разделе «Хуки» при
включённом главном выключателе появляется «Отключить песочницу (ОПАСНО)». **По умолчанию выключено**, а перед включением приложение
показывает предупреждение «ОПАСНО!» с кнопками «Отмена» / «Всё равно отключить». Само поле `unsafe_java` ничего не включает.

Когда пользователь включил хуки и отключил песочницу, плагин перезапускается, и **только для него** появляется:

* `luajava` (LuaJ): `luajava.bindClass("java.lang.Class")`, `luajava.newInstance(...)`, вызов методов Java-объектов как `obj:method()`;
  через рефлексию доступны и приватные поля приложения;
* `app.context()` — `Context` приложения;
* `app.viewmodel()` — сам `AppViewModel`.

Остальные плагины по-прежнему в песочнице. Ограничение времени на вызов (3 секунды) и сторож остаются. Выключили хуки или песочницу —
плагин перезапускается без `luajava`, а его хуки получают `false`. Такой плагин может всё, что может приложение: читать токены и
данные, ходить в сеть, ломать приложение; ставьте их только из источников, которым полностью доверяете. Пример — `exm.no-restrictions`.

### Поиск — `app.search(запрос)`

Открывает вкладку «Поиск» с этим запросом.

### Таймеры — `timer`

`timer.after(мс, функция)`, `timer.every(мс, функция)` → id; `timer.cancel(id)`; `timer.cancel_all()` — снять все свои таймеры; `timer.now()` — время в мс.
Минимальный интервал 500 мс, до 16 таймеров на плагин.

## Иконка

В манифесте: `"icon": "icon.png"` (png, jpg или webp, до 512 КБ и не больше 1024×1024 пикселей). Иконка показывается в списке
плагинов и в окне установки; без неё — стандартный значок.

## Установка

Файл `.exm` открывается из файлового менеджера или через «Установить из файла .exm»: снизу появляется окно с иконкой,
описанием и кнопкой «Установить» (или «Обновить»). Новый плагин появляется в списке с анимацией, при удалении — уезжает.
Главный выключатель «Система плагинов» (по умолчанию включён; при установке плагина включается сам) включает и выключает все плагины сразу; у каждого плагина есть и свой переключатель.

## Песочница и ограничения

* Недоступны: `io`, `os.execute/remove/…`, `debug`, `load`, `loadstring`, `dofile`, `loadfile`, `coroutine`, `luajava`, `package`. Исключение: `luajava` появляется у плагина, для которого пользователь отключил песочницу (см. «Отключённая песочница»).
* Весь Lua-код всех плагинов выполняется в одном фоновом потоке — интерфейс не тормозит.
* **Лимит времени на один вызов — 3 секунды** (запуск, обработчик события, таймер). Ожидание сети и команд плеера в лимит не
  входит. Скрипт, который завис, будет остановлен, а плагин выключен (появится уведомление).
* **Память:** если за один вызов скрипт занял больше ~96 МБ, он останавливается. Строки через `string.rep` — не больше 1 МБ,
  шаблоны `find/match/gmatch/gsub` — строка до 16 КБ и шаблон до 120 символов, `string.format` — без огромной ширины/точности.
* **Сторож:** отдельный поток следит за скриптами. Если скрипт завис там, где не работает счётчик инструкций, поток Lua
  заменяется новым, плагин выключается, остальные плагины перезапускаются.
* **Частота:** `ui.toast` — раз в 1,5 с, `wave.start` — раз в 10 с, `app.search` — раз в 2 с, не больше 200 действий над интерфейсом за один вызов.
* Ошибки скрипта не роняют приложение: они пишутся в журнал и показываются в списке плагинов (Настройки → Плагины).
* Скрипт запускается заново при каждом включении плагина и при старте приложения; между запусками сохраняется только `storage`.
* Скрипты работают, пока приложение запущено. Когда приложение полностью закрыто, события не приходят.

## Примеры

Готовые плагины лежат в `plugins-examples/` (исходники — в `plugins-examples/src/<id>/`):

| Плагин | Что делает |
|--------|------------|
| `exm.time-theme` | Цвет акцента и AMOLED по времени суток |
| `exm.track-toast` | Уведомление «Играет: …» при смене трека |
| `exm.listen-stats` | Счёт треков за день, любимые исполнители; поле, переключатель и кнопка сброса в настройках |
| `exm.smart-wave` | Станции волны под время суток (`require` + `stations.lua`) |
| `exm.sleep-timer` | Пауза после N минут с плавным затуханием (ползунки в настройках) |
| `exm.no-restrictions` | NoRestrictions: Java-код плагина через `luajava` (нужны хуки и отключённая песочница) ставит аккаунту признак Плюса на этом устройстве: нет обрезки до 30 секунд и есть значок Плюса. В приложении под него кода нет |
| `exm.settings-demo` | Страница настроек целиком из Lua (`ui.settings_page`): пункт в Настройках, условные поля, цвет, ползунок, кнопки; окна `ui.confirm` / `ui.prompt` / `ui.dialog` и модалка `ui.sheet` |

Собрать свой плагин: положить папку в `plugins-examples/src/<id>/` и выполнить `python3 plugins-examples/build.py <id>` —
получится `<id>.exm`. Скрипт перед упаковкой проверяет манифест теми же правилами, что и приложение.
Установка: Настройки → Плагины → «Установить из файла .exm» (или открыть файл из файлового менеджера).

### Минимальный плагин

```lua
-- main.lua
events.on("play_state", function(playing)
  ui.toast(playing and "Играет" or "Пауза")
end)
```

## Безопасность: что гарантируется и чего нет

Гарантируется (проверено в коде):
* Скрипт не видит файлы, процессы, другие плагины, токен и данные аккаунта Яндекса; из Lua нельзя вызвать Java-классы (кроме плагина с отключённой пользователем песочницей).
* Плагин может делать только то, что есть в API выше (плеер, уведомления, хранилище, сеть, тема, волна, поиск).
* Сеть — только `https`, к локальным и служебным адресам (127.x, 10.x, 192.168.x, 169.254.x, fc00::/7, 100.64/10) обратиться нельзя;
  адрес проверяется при каждом соединении, редиректы не выполняются, 30 запросов в минуту, тело ответа до 1 МБ.
* Архив `.exm` проверяется при установке: размер, число файлов, имена без `..`, размер иконки, формат манифеста; настройки проверяются приложением.
* Данные плагина (`storage`, настройки) лежат отдельно для каждого плагина и стираются при удалении.

Остаточные риски (их нельзя убрать полностью, поэтому ставьте плагины только из источников, которым доверяете):
* Плагин, который использует `http` и `player`, может отправлять в интернет то, что вы слушаете.
* Плагин, который вызывает `wave.start`, может запустить волну (раз в 10 секунд) и заменить текущую очередь.
* Скрипт, который завис в нативной функции Java, продолжит греть процессор в брошенном потоке, пока приложение не перезапустят,
  хотя плагин будет выключен, а остальные продолжат работать.
* Лимит памяти приблизительный: он считает рост кучи всего приложения за время вызова.
