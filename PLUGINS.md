# Плагины (.exm)

Плагин — **один файл `.exm`**: обычный ZIP-архив с манифестом `manifest.json` и **Lua-файлами** (плюс необязательная иконка).
Приложение хранит плагин одним файлом (`files/plugins/<id>.exm`) и читает манифест и скрипты прямо из архива.

Где в приложении: Настройки → Плагины (главный выключатель, список, установка из файла). Файл `.exm` можно открыть и из
файлового менеджера: внизу появится окно с описанием плагина и кнопкой «Установить». Плагины добавляются и удаляются с анимацией.

Старый «декларативный» вид плагинов (только цвет и станции волны в манифесте, без кода) убран. Всё то же делает Lua-скрипт:
`theme.set_accent(...)`, `theme.set_amoled(...)`, `wave.add_station(...)`. Полное описание API — в `PLUGINS_LUA.md`.

## Структура

```
plugin.exm (ZIP)
├── manifest.json     обязательно
├── main.lua          главный скрипт (имя задаётся в манифесте)
├── *.lua             любые другие модули (подключаются через require)
└── icon.png          необязательно (png / jpg / webp, до 512 КБ)
```

## manifest.json

```json
{
  "id": "demo.hello",
  "name": "Привет",
  "version": "1.0.0",
  "author": "Автор",
  "description": "Что делает плагин",
  "api": 2,
  "icon": "icon.png",
  "contributes": {
    "lua": { "main": "main.lua" }
  }
}
```

| Поле | Описание |
|------|----------|
| `id` | 3–64 символа: латиница, цифры, `.`, `-`, `_`. Одинаковый id = обновление плагина |
| `name`, `version` | обязательны (имя до 60 символов, версия до 24) |
| `author`, `description` | необязательны |
| `api` | версия API (сейчас `2`); плагин для более нового API не установится |
| `icon` | имя файла иконки внутри архива (если с иконкой что-то не так, плагин всё равно установится) |
| `contributes.lua.main` | главный Lua-скрипт — **обязателен** |
| `contributes.settings` | необязательные настройки плагина (рисует приложение), см. `PLUGINS_LUA.md` |
| `contributes.hooks` | необязательные хуки: плагин сам объявляет их (`id`, `title`, `summary`), а код хука пишет в своём Lua (`hooks.on`). Если хуки объявлены, в настройках плагина всегда есть выключатель «Включить хуки» (по умолчанию **выключен**), и при установке приложение спрашивает, включать ли их. См. `PLUGINS_LUA.md` |
| `contributes.unsafe_java` | `true` — плагину нужен Java-код из Lua. Тогда при включённых хуках пользователь может **отключить песочницу** для этого плагина (ОПАСНО; по умолчанию выключено, перед включением показывается предупреждение). См. `PLUGINS_LUA.md` |
| `contributes.settings_entry` | необязательный свой пункт плагина в главных Настройках (`{"title", "summary"}` или `true`), см. `PLUGINS_LUA.md` |

Права (`permissions`) объявлять **не нужно**: любому включённому плагину доступно всё API (плеер, уведомления, хранилище,
сеть, тема, волна, поиск). Поле `permissions`, если оно есть в старом манифесте, игнорируется.

## Ограничения
Файл до 20 МБ, до 256 файлов в архиве, имена без `..` и `\`, скрипт до 512 КБ. Всё лишнее отклоняется с понятным сообщением.

## Примеры
В `plugins-examples/` лежат готовые плагины (`*.exm`) и их исходники (`src/<id>/`). Сборка: `python3 plugins-examples/build.py`.

## Безопасность
Плагин выполняется в песочнице: нет `io`, `os.execute`, `debug`, `load`, `package`, нет доступа к файлам и к данным приложения, у каждого плагина своё хранилище.
- **Сеть:** только `https`; адреса локальной сети, `localhost`, IP-литералы из частных диапазонов и адреса, в которые разрешается имя, отклоняются при каждом запросе; редиректы и системный прокси отключены; не больше 30 запросов в минуту.
- **Лимиты:** время на один вызов, память, размер строк (`string.rep`, `string.gsub`), число значений в `table.unpack` / `string.byte`.
- **Установка:** проверяются имена в архиве (без `..`, `\`, управляющих символов, дубликатов), число записей, размеры файлов и иконки до декодирования; `file://` на закрытые данные приложения не читается.
- Установка и обновление плагина всегда требуют подтверждения. Обновление плагина с тем же `id` наследует его хранилище — ставьте плагины только из источников, которым доверяете.
- Проверить песочницу на устройстве можно плагином `exm.api-test` (кнопка «Запустить самотест»).
